# فهرست اکشن‌ها و قراردادهای پنل

این فهرست از ActionDescriptor واقعی MVC بدون اجرای entrypoint استخراج شد؛ ۱۲۱ اکشن. نبود محدودیت verb به معنی موفقیت هر body نیست. routeهای convention با تنظیم‌های ترکیبی UseMvc و UseEndpoints و reverse proxy باید در host ایزوله تأیید شوند. هیچ action این جدول invoke نشده است.

پروفایل‌ها: R طبق سند قرارداد؛ J پاسخ Json بدون envelope ثابت؛ V صفحهٔ HTML/redirect؛ T callback با Task. خطاهای MVC ممکن است400/415، middleware400/401/404 و challenge پنل302 تولید کنند. آیندهٔ قرارداد legacy ثابت است، مگر تغییر امنیتی مصوب.

## پاسخ و null در پنل

List/Detailها J دادهٔ DTO یا entity می‌دهند؛ wrapper عمومی R ندارند. mutationهای معمول status رشتهٔ "1" دارند، نه enum عددی. UploadFile می‌تواند302 به Index و در catch status رشتهٔ "2" بدهد؛ GetZoneIds catch با status رشتهٔ "0" هم دارد. IPConfig.Create عملاً write نمی‌کند ولی موفق اعلام می‌کند؛ DeleteInactive حذف‌ها را await نمی‌کند. Taskهای آمار بدون await خروجی قطعی DTO محسوب نمی‌شوند.

ترتیب: Apps.List و Groups بر UpdatedAt نزولی، Domains بدون order و filter دو شاخهٔ یکسان، IPConfig.GetAll بدون filter/order، ListInactive روی !active و deleted، Isp/Operator بر Id نزولی، logها بر Id نزولی و job listing از DB/MemoryStorage. این listها pagination سمت SQL ندارند. data:[]، data:null، raw array و HTML نباید یکسان‌سازی خاموش شوند. null/type و قالب date/number طبق schema و پروفایل مشترک قرارداد است؛ defaultهای CLR مقدارهای عددی0 و bool=false و reference=null هستند مگر initializer یا action مقدار بدهد.

## Razor Pages میزبان اصلی

`/Index` و ریشه طبق convention صفحهٔ Index، `/Privacy` و `/Error` در Pages وجود دارند؛ قرارداد مصرف Android برای آن‌ها اثبات نشده.
