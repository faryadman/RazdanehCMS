# گزارش امنیت

این گزارش ارزیابی کد در commit مبناست؛ exploit روی محیط واقعی انجام نشده است. «وجود نقص کدی» با «بهره‌برداری موفق در تولید» تفاوت دارد. مقدار credential، نام میزبان خصوصی و محتوای backup در گزارش درج نشده‌اند.

## محدودیت و اقدامات فوری پیشنهادی

این PR فقط مستندات است و هیچ مشکل فوق را اصلاح نمی‌کند. P0: محدودکردن دسترسی عملیات مدیریتی در لبه با طرح بازگشت و شناسایی مصرف‌کننده، تعیین تکلیف secretهای افشاشده با مالک، منع deletion گستردهٔ DNS پس از baseline تست. محدودسازی لبه توصیه است و در این جلسه اعمال نشده است.

HTTPS redirect در میزبان اصلی وجود دارد؛ این به معنی TLS معتبر برای SQL نیست. اتصال‌های literal و بعضی تنظیمات SQL verification/encryption را تضعیف می‌کنند. استفادهٔ استاندارد از EF/پارامتر Dapper به‌خودی‌خود SQL injection نیست. JwtSettings داشتن به معنی JWT authentication فعال نیست؛ در میزبان اصلی Identity cookie فعال است. audit log تجاری برای هر تغییر DNS، سابقهٔ مستقل lease و کنترل overlap در کد حاضر وجود ندارد.
