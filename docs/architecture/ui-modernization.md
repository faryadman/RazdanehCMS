# نوسازی تدریجی پنل

مبنای پیشنهادی همان MVC/Razor و AJAX است؛ React برای این scope توجیهی ندارد. هدف اول صحت داده و مجوز عملیات است، سپس زیبایی. پنل Web.Admin قدیمی جایگزین آماده نیست.

۱. فرم‌ها و جدول‌های موجود را با ViewModel کوچک، formatter تاریخ واحد و null/empty state اصلاح کنید. JSON خراب یک ردیف نباید جدول را متوقف کند؛ متن raw برای اصلاح مدیر حفظ شود، بدون چاپ در console.
۲. جدول سرورها/دامنه‌ها به endpoint نسخه‌دار admin با pagination، filter و sort سمت SQL متصل شود؛ از تغییر array API قدیمی اجتناب شود. شمارش و مجموع فیلترشده معنی مشخص داشته باشد.
۳. layout فارسی RTL، فاصله‌گذاری و کنتراست خوانا، جدول responsive و editor JSON با جهت LTR؛ label و خطای field مرتبط و دسترسی keyboard فراهم باشد.
۴. loading state و disable دکمه از ارسال تکراری جلوگیری کند ولی idempotency backend لازم است. خطا فرم را نبندد و مقدار کاربر پاک نشود؛ success فقط بعد از commit.
۵. DNS/delete و تغییر گروه جمعی confirmation با دامنهٔ دقیق اثر و تعداد واقعی داشته باشد؛ نتیجهٔ جزئی با شناسه و خطای پاک‌سازی‌شده نمایش داده شود.
۶. مقادیر دیتابیس با renderer متنی/DOM امن نمایش داده شوند؛ الحاق HTML رشته‌ای از host/name/fileName حذف شود. نمایش یا برگرداندن ApiKey موجود به فرم ممنوع؛ فقط وضعیت پیکربندی و امکان جایگزینی امن.
۷. داشبورد job وضعیت config را از execution جدا کند؛ اطلاعات next/last از store پایدار و زمان UTC با نمایش منطقهٔ مشخص بیاید. کپی برنامهٔ قدیمی فقط بر پایهٔ Hangfire MemoryStorage صحت را تضمین نمی‌کند.

پذیرش: دادهٔ null، JSON خراب، نام با `<` و `&`، صفحهٔ آخر، خطای شبکه، conflict و درخواست تکراری با fixture کنترل‌شده آزمایش شود. آزمون browser هنوز اجرا نشده و تصویر جدیدی در این ممیزی ساخته نشده است.
